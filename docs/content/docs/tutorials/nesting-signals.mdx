This tutorial covers nesting Signals inside each other - a Signal that holds a list of items, where every item is an object of its own Signals - so you can add and remove items at runtime while each item stays independently reactive.

**Prerequisites:** Complete [Composing Signals](/docs/tutorials/composing-signals) first.
